## 中心メッセージ
- 計画 = 「明確な目的意識と実行可能な道筋を描いた段取り」。
- 「段取り八割」を超えて「計画10割」。計画が仕事の成否を分ける最重要要素。
- 計画力は才能やセンスではなく、正しい知識＋訓練で誰でも身につくスキル。

## 本書が掲げる4つの価値
| 価値 | 意味 |
|---|---|
| 再現性 | 誰でも同じ手順で実践できる |
| 実践性 | 明日から使える |
| 網羅性 | 目的設定→実行→管理まで体系的にカバー |
| 普遍性 | 仕事の大小を問わず応用可能 |

## 対象読者
進め方に悩む20〜30代 / 自己流に限界を感じる人 / 初めてリーダー・PM担当になった人 / 部下指導が必要な立場の人。

## 構成（2部・8章）
**基礎編：計画立案の土台**
- 第1章 計画とは何か？
- 第2章 あなたが携わる2種類の仕事と計画（定常業務 vs プロジェクト）
- 第3章 日々の自分の計画の立て方を振り返ろう

**実践編：計画の4ステップ**（本書の核心）
- 第4章 計画立案の「型」を手に入れる（4ステップ全体像）
- 第5章 STEP1 土台を作る — なぜやるのか/どこまでやるのか（目的・ゴール・スコープ）
- 第6章 STEP2 部品をそろえる — 具体的に何をやるのか（タスク分解WBS＋ヒト・モノ・カネ）
- 第7章 STEP3 組み立てる — いつ・誰が・どの順番で（スケジュール・体制図・クリティカルパス）
- 第8章 STEP4 維持管理ルールを決める — どうやって管理するか（進捗確認・リスク管理・変更管理）

## 押さえどころ（書評・著者「はじめに」から）
- 計画倒れを防ぐ要 = スコープで「やること」だけでなく **「やらないこと」を決めて関係者と合意**する。
- STEP2の資源洗い出しは「ヒト・モノ・カネ」の3観点。不足（穴）の発見が目的。
- STEP3でクリティカルパスを特定し、そこを最優先で守る。
- STEP4にはリスク管理・変更管理が含まれる。

## 注目: 生成AI活用法
本書は4ステップに沿った生成AIの使い方を紹介。特に評価が高いのは——
**過去プロジェクトの成功10件・失敗10件を、WBS／体制図／納品物資料ごと生成AIに読み込ませ、新規プロジェクトの計画アドバイスを得る**手法。
